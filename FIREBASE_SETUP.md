# Firebase removed

Firebase is no longer part of this app.

- No `google-services.json`
- No `GOOGLE_WEB_CLIENT_ID`
- No Google sign-in gate
- Mentor, 3D, diagnostics, OBD/FORScan, and local records open on launch

Gemini still uses `GEMINI_API_KEY` through the existing REST client in `GeminiApiService.kt`.
