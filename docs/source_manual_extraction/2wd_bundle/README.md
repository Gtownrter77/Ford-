# Local Service-Manual Extraction: 2WD Bundle

This directory contains derived indexes and project reports produced from the local Lemon archive downloaded for this project. The archive is explicitly labeled **2004 Ford Explorer Sport Trac 2WD V6-4.0L VIN K Flex Fuel**. It is retained for provenance and search context only and must not be treated as 4WD factory source material.

The raw manual HTML and image archive remain outside GitHub because the bundle fitment is 2WD and the repository’s authoritative 4WD wiring source is the embedded CHARM package at `docs/wiring_diagrams/charm_4wd_vin_k/`. The CSV, Markdown index, summary JSON, archive inventory, and model-build summary are derived artifacts, not a replacement for a licensed 4WD EVTM/WSM.

The 4WD Blender scripts and validation outputs are stored separately under `technical_model/2004_explorer_sport_trac_4wd/`.
