# Complete 4WD VIN K Electrical Diagram Source Package

This directory embeds the complete source-file collection fetched from the live Operation CHARM 4WD VIN K tree for the 2004 Ford Explorer Sport Trac 4WD V6-4.0L VIN K Flex Fuel configuration.

Each category directory contains the source HTML page, `metadata.json`, and any linked PNG diagram plates. The root `index.json` records the live tree URL, category URLs, plate URLs, filenames, byte sizes, and HTTP discovery results. The fetcher is retained at `tools/crawl_charm_4wd_vin_k.py` so the package can be reproduced.

The images are source plates, not redrawn project graphics. Use the labels and connector references on the plates as the authority for the diagram family. The repository intentionally does not claim that the old 2WD Lemon bundle is a 4WD source; these files were fetched from the explicit 4WD VIN K CHARM tree.

Source hub: https://charm.li/Ford/2004/Explorer%20Sport%20Trac%204WD%20V6-4.0L%20VIN%20K%20Flex%20Fuel/
