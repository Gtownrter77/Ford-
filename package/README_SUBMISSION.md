# Ford Sport Trac Mentor — Submission Package

## Project summary

Ford Sport Trac Mentor is an Android application for a 2004 Ford Explorer Sport Trac with the 4.0L SOHC V6 and 4WD configuration. It combines a procedural/GLB technical vehicle model, a safety-first diagnostic Mentor, selected manual evidence, and read-only OBD-II/FORScan ELM327 integration.

## Included features

- Mandatory Google-account sign-in gate using Android Credential Manager and Firebase Authentication.
- Protected app shell for the Mentor, 3D model, manual, diagnostics, maintenance, and parts areas.
- Configuration-aware safety guidance for A/C, oil pressure, heating/cooling, and timing-chain symptoms.
- Classic-Bluetooth ELM327 transport with standard PID polling and DTC decoding.
- Source-aware Mentor architecture with explicit limits on unindexed corpus claims.
- Offline diagnostic fallback and technician handoff concepts.

## Build and test status

The repository build passed `testDebugUnitTest` and `assembleDebug` before this package was assembled. The APK is not a release-signed production artifact. Physical-device acceptance is still pending because it requires a configured Firebase project, a real Android device, Google sign-in, and Bluetooth/OBD testing.

The current package does not include `google-services.json`, OAuth secrets, private keys, user tokens, or device logs. Configure Firebase by following `docs/FIREBASE_SETUP.md` before installing the APK for authentication testing.

## Safety boundary

This package is a diagnostic and learning aid. It is not an OEM-certified CAD package, a full FORScan desktop replacement, or autonomous repair authorization. Do not drive or perform safety-critical work solely from app output. Follow stop-and-tow guidance and obtain qualified physical inspection when oil-pressure warnings, overheating, smoke, active leaks, severe timing noise, brake hazards, or other unsafe conditions are present.
