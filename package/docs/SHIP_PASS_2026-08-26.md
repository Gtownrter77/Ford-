## How to install the APK
This sandbox has no Android SDK. On the phone/dev machine:

```
git clone https://github.com/Gtownrter77/Ford-.git
cd Ford-
./gradlew :app:assembleDebug
```

Install `app/build/outputs/apk/debug/app-debug.apk`.
