7. Brakes: DOT 3. CHARM Brakes. Lugs OG 84-114.
8. Steering/suspension: CHARM those leaves. Confirm VIN K before using packaged chassis torques.

11. Body/glass/bed: CHARM Body + Windows. Rear-window drains before motors.
